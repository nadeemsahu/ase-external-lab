# Student Assignment Tracker - User Stories

## 1. Add a New Assignment
**As a student**, I want to add a new assignment with a title, course name, and due date so that I can track my coursework and upcoming deadlines.

## 2. Mark Assignment as Complete
**As a student**, I want to mark an assignment as complete or incomplete so that I can track my progress and see what still needs to be done.

## 3. View Assignments Listed by Due Date
**As a student**, I want to see all my assignments listed sorted by due date (earliest first) so that I can prioritize what to work on first.

## 4. Edit Assignment Details
**As a student**, I want to edit an existing assignment's title, course, or due date so that I can keep information up to date when syllabus changes or deadlines shift.

## 5. Delete an Assignment
**As a student**, I want to delete an assignment so that I can remove items I no longer need (e.g., a dropped course or completed work already removed).
